# A Bonfire Parley

A slow, 1-bit dithered walking survival game. Carry a relic through a snowbound country. Stay near heat. When a stranger keeps a fire, sit, and speak.

Inspired by the bleak miniature-set look of contemporary dithered journey games — legally distinct original work.

## Play

- **Move:** WASD / arrows / left stick / on-screen stick
- **Act:** Space / E / gamepad A / Act button — rest, scavenge, eat, or parley
- **Mute:** M

Warmth is the clock. The pack grows heavier the farther you walk. Reach the last fire, or freeze on the road.

## Install on iPhone

1. Open the site in Safari
2. Tap the Share button
3. Tap **Add to Home Screen**
4. Launch it like an app — it runs fullscreen

## Develop

```
npm install
npm run dev
```
